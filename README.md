# 耳コピ図鑑

相対音感を鍛えるための耳コピ練習アプリ。移動ドで、知っているメロディをドレミで歌えるようになるための「図鑑」です。

公開ページ: https://kinakobooster.github.io/mimizukan/

## 使い方

1. 「＋ 新しい曲」でタイトルをつける
2. 曲の終わりの音を想像して鍵盤で探す。見つけたらその鍵盤を**下にスワイプ**するとキーが決まり、鍵盤の表記がその調のドレミに変わる
3. 鍵盤を下にスワイプすると、カーソル位置にドレミが入る。押している間は音が鳴り続ける
4. ▶ で最初から再生。␣ で区切り、↵ で改行（別パートなど）、⌫ で1音消す
5. 「⋯」からテキスト書き出し・共有リンク・削除。一覧の「書き出し／取り込み」で図鑑全体をテキストでやりとりできる

## 表記

- 半音は デ・リ・フィ・サ・チ（ド デ レ リ ミ ファ フィ ソ サ ラ チ シ）
- 短調は単にラで終わる曲として扱う（キーは平行長調のドで記録）
- 「ー」で音を伸ばす、空白・読点で休符、改行で長めの休符

## テキスト形式

```
きらきら星
キー: G
ドドソソララソ
ファファミミレレド
```

複数曲は `---` の行で区切ります。ブラウザの localStorage に保存されます。
