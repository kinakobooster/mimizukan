# 耳コピ図鑑

相対音感を鍛えるための耳コピ練習アプリ。移動ドで、知っているメロディをドレミで歌えるようになるための「図鑑」です。

公開ページ: https://kinakobooster.github.io/mimizukan/

## 使い方

1. 「＋ 新しい曲」でタイトルをつける
2. 曲の終わりの音を想像して鍵盤で探す。見つけたらその鍵盤を**下にスワイプ**するとキーが決まり、鍵盤が移調される（C の位置が「ド」になり、押すとその調の高さで鳴る）
3. 鍵盤を下にスワイプすると、カーソル位置にドレミが入る。押している間は音が鳴り続ける
4. 右上の「キー」バッジを**上下にスワイプ**すると半音ずつカチカチ移調できる（上で高く、下で低く。ドレミはそのまま、鳴る高さだけ変わる）
5. ▶ で最初から再生。␣ で区切り、↵ で改行（別パートなど）、⌫ で1音消す
6. 「⋯」からテキスト書き出し・共有リンク・削除。一覧の「書き出し／取り込み」で図鑑全体をテキストでやりとりできる

## 表記

- 半音は デ・リ・フィ・サ・チ（ド デ レ リ ミ ファ フィ ソ サ ラ チ シ）
- 短調は単にラで終わる曲として扱う（キーは平行長調のドで記録）
- オクターブは、ド〜シの基準の高さは無印、1つ上は「↑」、2つ上は「↑↑」、1つ下は「↓」を音の後ろに付ける（例: ソ↓ドミソ ド↑）
- 「ー」で音を伸ばす、空白・読点で休符、改行で長めの休符

## テキスト形式

```
きらきら星
キー: G
ドドソソララソ
ファファミミレレド
ソソファファミミレ
```

複数曲は `---` の行で区切ります。ブラウザの localStorage に保存されます。
